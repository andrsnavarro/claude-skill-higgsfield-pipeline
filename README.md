# claude-skill-higgsfield-pipeline

A production manual skill for AI filmmaking, from brief to Seedance review, with naming conventions, model selection and proof checklists. Claude replies in your language, model prompts are in English.

## Install

Copy this folder into your skills directory, for example `~/.claude/skills/higgsfield-pipeline`.
